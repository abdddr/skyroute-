About SkyRoute

SkyRoute is a student project by Kagan Tasbolat and Abdrakhman Almukhan, built for the Web Technologies course at Astana IT University. It shows how a flight-booking website can be built with HTML, CSS, Flexbox, Bootstrap and a little JavaScript.

It is a demo: flights, prices and bookings are examples, and no real tickets are sold.

  • Home base: Astana (NQZ)
  • Nine nonstop domestic routes
  • Fares from $28 one-way
